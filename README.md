# Prime Theme for Moodle

A modern, customizable theme for Moodle with a focus on visual blocks, sliders, and an enhanced user experience.

## Overview

Prime is a Moodle theme designed to give your learning site a professional and engaging look. It includes a variety of custom blocks and layout templates that allow administrators and teachers to build rich, visually appealing course pages and front pages without needing to write code.

The theme extends the standard Moodle functionality with features like:
- Custom "Highlighted" (Destacado) blocks with images and call-to-action buttons.
- "My Courses" grid and slider blocks for personalized course displays.
- Site features grids with icons and descriptions.
- Enhanced user menu with first name and last name display.

## System Requirements

Before installing, ensure your Moodle site meets the following requirements:

- **Moodle Version:** This theme is compatible with Moodle 4.x (and may require specific versions; please check the theme's version.php file for exact compatibility).
- **Dependencies:** The theme extends `theme_boost` and may require it to be installed.

## Installation

Installing the Prime theme is straightforward and can be done through the Moodle interface or manually.

### Installation via Moodle UI (Recommended)

1. Download the theme ZIP file from the Moodle Marketplace or the [GitHub repository](https://github.com/your-repo).
2. Log in to your Moodle site as an administrator.
3. Go to **Site administration > Plugins > Install plugins**.
4. Upload the ZIP file and follow the on-screen instructions.
5. After installation, go to **Site administration > Appearance > Themes > Theme selector** and select "Prime".

### Manual Installation

1. Download and unzip the theme package.
2. Rename the unzipped folder to `prime`.
3. Upload the `prime` folder to the `/theme/` directory of your Moodle installation.
4. Log in to Moodle as an administrator and visit the notifications page to complete the installation.
5. Select the theme from the Theme selector.

## Configuration

After installation, you can configure the theme's settings from:
**Site administration > Appearance > Themes > Prime**.

From there, you can adjust colors, fonts, and other visual options to match your institution's branding.

## Usage

Once installed and configured, the theme provides several custom blocks that can be added to any page:
- **Destacado (Highlighted) Block:** Add a featured section with an image, title, and button.
- **My Courses Grid:** Show the logged-in user's courses in a filterable grid.
- **My Courses Slider:** A responsive carousel of courses.
- **Site Features / Indicator Block:** Display a grid of features with icons.

Simply add these blocks via the block drawer on any Moodle page.
